# Changelog

## 0.1.1

- The Esc menu no longer pauses by default: F8 is the pause. Set `PauseOnMenu` to `true` to get the old behaviour back. Config files from 0.1.0 keep their saved value, so change it there to get the new default.
- Press-and-hold menu buttons such as Retire to Lobby work while paused. Leaving the expedition from a paused menu resumes the game first.

## 0.1.0

- Solo: the Esc menu pauses the game, and the hotkey (F8) toggles a pause without the menu.
- Multiplayer: any player with the mod can pause the whole squad. On by default; the host can turn it off.
- Game audio freezes during a pause and picks up where it stopped.
